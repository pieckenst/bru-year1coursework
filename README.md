# Курсовой проект: Учет продаж проездных билетов

Этот репозиторий содержит курсовую работу по дисциплине «Основы алгоритмизации и программирования» на тему: разработка программы учета продаж проездных билетов. Проект реализован с использованием C# (основная реализация, современные интерфейсы) и Java (отдельные вспомогательные компоненты), включает настольные, мобильные и административные компоненты, а также библиотеки для построения динамических форм.

## Описание

**Цель проекта** — автоматизация учета и управления продажами проездных билетов для автотранспортного предприятия.  
Программа предназначена для работы как с клиентской, так и с административной стороны, позволяет вести учет билетов, реализовывать продажи, формировать отчеты и управлять пользователями.  
В рамках курсовой работы реализованы современные интерфейсы (Avalonia, MAUI, WinForms), поддерживается кроссплатформенность, большая часть логики вынесена в отдельные сервисы и библиотеки для повторного использования.

## Функциональные возможности

**Согласно документации и приложенным документам (курсовая записка, задание, содержание):**

- **Учёт продаж билетов:** регистрация новых продаж, возвратов, списание неиспользованных билетов.
- **Ведение реестра билетов:** учёт типов билетов (разовые, месячные, льготные и др.), генерация уникальных номеров.
- **Работа с пользователями:** авторизация, разграничение прав (кассир, администратор, контролёр и т.д.), журналирование действий.
- **Формирование отчётов:** по продажам, выручке, остаткам, периодам, сотрудникам.
- **Управление маршрутами и рейсами:** хранение информации о маршрутах, расписании, автобусах.
- **Администрирование:** добавление/редактирование пользователей, контроль операций, резервное копирование данных.
- **Импорт/экспорт:** поддержка выгрузки данных в стандартные форматы (Excel, CSV), печать документов.
- **Мобильный интерфейс:** работа с билетами и продажами на мобильных устройствах.
- **Динамические формы:** генерация UI на лету для различных задач администрирования и учёта (динамические формы реализованы через DynamicForms).

## Реализация

**Технологии:**
- Язык: C# (основные модули, UI, бизнес-логика), Java (отдельные учебные компоненты/задания)
- UI: Avalonia (кроссплатформенный современный UI), Windows Forms (WinForms + DevExpress), MAUI (мобильный UI)
- Сервер: REST API на C# (ASP.NET Core)
- Хранение данных: файловая система/SQLite (демо-режим), возможно расширение до PostgreSQL/MSSQL
- Работа с отчетами: интеграция с Excel, генерация документов

**Архитектура:**
- **Модульность:** Чёткое разделение на ядро бизнес-логики, сервисы, интерфейсы и административные панели.
- **Динамические формы:** Использование собственного движка (DynamicForms) для генерации форм, что облегчает быстрое добавление новых сущностей.
- **Права доступа:** Гибкое разграничение по ролям, интеграция с системой логирования и контроля.

**Административные интерфейсы:**
- **SuperNova** — современный административный интерфейс на Avalonia, реализующий визуальный редактор форм, расширенные отчёты, гибкую навигацию и панель управления для админа и старшего кассира.
- **LegacyForms.DX.Windows** — классический интерфейс на WinForms (DevExpress), реализующий все базовые функции учёта и продаж.

**Мобильное приложение:**
- **MAUI-клиент** — для работы на Android/iOS, поддержка офлайн-режима (кэширование операций), синхронизация с сервером.

## Основные компоненты и папки

### SuperNova (и подмодули: SuperNova.Runtime, SuperNova.Desktop, SuperNova.Standalone)
**SuperNova** — это современный административный интерфейс на Avalonia, предоставляющий:
- визуальный редактор форм и отчётов
- расширенное администрирование пользователей и маршрутов
- систему поиска и фильтрации данных
- поддержку динамических форм (через собственный движок)
- тестовые и демонстрационные режимы для обучения

### TicketSalesApp.*
- **UI.Avalonia:** Приложение для продаж и контроля билетов (клиентская часть)
- **UI.Administration.Avalonia:** Современный админ-интерфейс для управления кассами, пользователями, билетами
- **AdminServer:** Серверная часть (REST API) для обработки запросов клиентов и администраторов, централизованное хранение данных
- **Services:** Логика работы с билетами, пользователями, маршрутами, отчетами
- **Core:** Бизнес-логика, модели, правила валидации
- **Core.Legacy:** Архивная версия ядра для поддержки старых UI
- **Mobile.UI.MAUI:** Мобильный клиент для Android/iOS

### DynamicForms.Library.*
- **Avalonia/WPF/Core:** Универсальные библиотеки для динамической генерации пользовательских форм — используются для создания админ-панелей и расширяемых интерфейсов.

### TicketSalesApp.UI.LegacyForms.DX.Windows
WinForms + DevExpress интерфейс для Windows — классическая реализация для кассиров.

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```sh
   git clone https://github.com/pieckenst/bru-year1coursework.git
   ```
2. **Откройте нужное решение (.sln) в Visual Studio.**
3. **Восстановите NuGet-пакеты.**
4. **Соберите и запустите нужный проект:**
   - Для SuperNova, TicketSalesApp.UI.Avalonia — .NET 9 + Avalonia SDK
   - Для мобильного приложения — .NET MAUI + Android/iOS SDK
   - Для LegacyForms — .NET Framework 4.7+, DevExpress

> Возможна работа в демо-режиме без подключения к серверу (данные сохраняются локально).
